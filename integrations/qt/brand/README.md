# Brand assets: Brontide "Song Rung" look + RenHDrum logo

Generated by `tools/brand-icons.py` (Pillow + fontTools, build time only). Edit the script, not the outputs.

| Path | What |
|---|---|
| `icons/brontide-ns2.svg` / `.ico` / `-256.png` | Brontide-NS2 app icon (blue). The `.ico` holds 16–256 px; 16 / 24 / 32–48 px are drawn simplified, not downscaled. |
| `icons/brontide-oot.svg` / `.ico` / `-256.png` | Brontide-oot app icon (amber) |
| `logo/renhdrum-light.svg`, `renhdrum-dark.svg` | One-colour logo for dark / light backgrounds (settings dialog footer) |
| `logo/renhdrum-color-ondark.svg`, `-onlight.svg` | Colour logo (web, README, About) |
| `logo/renhdrum-mark.svg` | Mark only (square places, favicon) |
| `logo/renhdrum-{light,dark}-18(@2x).png` | Raster fallback when the host has no SVG plugin |
| `logo/renhdrum-color-on{dark,light}-28(@2x).png` | Raster colour logo for About dialogs without SVG |
| `fonts/` | IBM Plex Sans (variable) + IBM Plex Mono, SIL Open Font License 1.1 (`fonts/OFL.txt`), unmodified |
| `theme/palette.md` | Dark and Light colour tokens for Fusion + `QPalette` |
| `theme/song-rung.qss` | Thin stylesheet layer (radii, borders, cards, transparent game list) |
| `preview.png` | All sizes on dark and light taskbars |

Logo text is converted to outlines, so the SVGs do not need the font installed.

## Using the logo
- Settings dialog footer: one-colour version matching the theme, 18 px high, centred, after a thin divider; "Powered by" at about 70 % opacity; clicking opens the RenHDrum repository.
- Keep clear space around the logo at least the height of the capital letters. Do not stretch, recolour (other than the files here) or separate the mark from the word.

## Using the icons in a Qt host
- Windows exe icon: reference the `.ico` from the `.rc` file. Window icon: `QIcon(":/brand/brontide-ns2.svg")` needs the `qsvg` image plugin at run time (`imageformats/qsvg.dll`); otherwise use the `.ico` / PNG.
